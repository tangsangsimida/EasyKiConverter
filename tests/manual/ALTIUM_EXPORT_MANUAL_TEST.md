## 3. 准备工作：导出测试数据

### 3.1 构建并启动程序

```bash
# 编译 Debug 版本
python tools/python/build_project.py -t Debug

# 启动程序
./build/bin/easykiconverter
```

### 3.2 导出步骤

#### 方式 A：通过 BOM 导入（推荐，覆盖 BOM 解析验证）

1. 启动程序后使用 BOM 导入功能，选择 `tests/fixtures/bom/testbom.xlsx`
2. 确认解析结果：R1/C1/U2 应成功导入，R2/J1/TP1 应被过滤
3. 等待所有元件数据预加载完成

#### 方式 B：手动逐个添加

1. 依次输入 LCSC ID：`C23186`、`C23166`、`C13564`、`C2040`
2. 等待所有元件数据预加载完成

#### 导出配置

打开导出设置对话框，配置如下：

| 设置项 | 值 |
|--------|-----|
| 目标格式 | **Altium** |
| 输出目录 | `tests/manual/export/` |
| 库名 | `ManualTest` |
| 导出符号 | **勾选** |
| 导出封装 | **勾选** |
| 导出 3D 模型 | **勾选**（WRL + STEP） |
| 覆盖已有文件 | **勾选** |

4. 点击导出，等待全部完成
5. 确认输出目录中生成了以下文件：

```
tests/manual/export/
├── ManualTest.SchLib          ← 符号库
├── ManualTest.PcbLib          ← 封装库
└── ManualTest.3dmodels/       ← 3D 模型目录（如适用）
```
