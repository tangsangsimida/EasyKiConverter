# 项目投稿材料

本文件夹用于存放各类项目投稿材料，按投稿目标分类管理。

## 目录结构

```
submissions/
├── 北京开元工业软件研究/    # 北京开元工业软件研究公开征集
└── README.md               # 本说明文件
```

## 添加新投稿

创建新的子文件夹，以投稿目标命名，例如：
- `某高校合作项目/`
- `某开源大赛/`
- `某企业合作/`

每个子文件夹内按需创建：
- 01-introduction/ - 项目简介
- 02-details/ - 详细介绍
- 03-docs/ - 文档资料
- 04-media/ - 媒体资源（图片、视频等）
- 05-demo/ - 可执行Demo
