# EasyKiConverter 项目简介

## 一句话描述

基于 Qt 6 和 MVVM 架构的现代化 C++ 桌面工具，将嘉立创 (LCSC) / EasyEDA 元件数据高效转换为 KiCad 库文件（符号 + 封装 + 3D 模型），支持 GUI 与 CLI 双模式。

## 项目简介

在国产 EDA 生态快速发展的背景下，大量电子工程师需要在嘉立创/LCSC 平台选型后，将元件数据迁移至开源 EDA 工具 KiCad 进行设计。然而，手动逐个创建符号、封装和 3D 模型耗时费力，且容易出错。EasyKiConverter 正是为解决这一痛点而生——它通过对接 EasyEDA 开放 API，一键获取元件的完整数据（电气符号、PCB 封装、3D 模型、预览图、数据手册），并自动转换为 KiCad 原生格式输出。项目采用 C++17 编写，基于 MVVM 架构实现了清晰的职责分层，支持多线程并行转换、BOM 批量导入、智能剪贴板提取等功能，同时提供现代化的 Qt Quick GUI 和纯命令行 CLI 两种运行模式，兼顾交互体验与自动化脚本需求。作为 GPL-3.0 开源软件，EasyKiConverter 已发布至 Flathub 和 Arch Linux AUR，支持 Windows、Linux、macOS 全平台。

## 核心功能

- **全流程转换**：支持 KiCad 符号 (.kicad_sym)、封装 (.kicad_mod) 及 3D 模型 (STEP/WRL/OBJ) 的完整导出，包括分体式符号转换
- **高效批量处理**：多线程并行转换 + BOM 文件导入 + 两阶段导出架构（预加载阶段并行获取所有元件数据 → 导出阶段按类型独立并行），充分利用多核性能
- **双模式运行**：现代化 Qt Quick GUI（深色/浅色主题）+ 纯 CLI 命令行模式，支持 Shell 自动补全（bash/zsh/fish）
- **智能辅助**：剪贴板智能提取元件编号、LCSC 预览图自动获取（缩略图 + 悬停预览）、配置实时自动保存与断点记忆
- **网络容错**：统一 NetworkClient 架构，按资源类型并发控制，支持自动重试与指数退避，弱网模式自动降级

## 技术亮点

- **MVVM 架构**：View (QML) → ViewModel → Service → Model 四层分离，UI 与业务逻辑完全解耦，可维护性强
- **两阶段导出引擎**：预加载阶段并行获取所有元件数据，导出阶段按类型（符号/封装/3D模型/预览图/数据手册）独立并行，库级导出单线程保证一致性
- **专用网络线程 + 分类型并发控制**：所有 HTTP 请求在独立网络线程中执行，9 种 ResourceType 各有独立的并发上限与重试策略，避免资源竞争
- **缓存自愈体系**：LRU 缓存淘汰 + 缓存健康检查 + 异步 metadata 落盘，缓存命中路径与网络路径性能一致
- **跨平台发布**：CMake 构建 + vcpkg 依赖管理，Flathub / AppImage / exe / dmg / AUR 多渠道分发

## 应用场景

- **硬件工程师选型转库**：在 LCSC 完成选型后，一键将元件转为 KiCad 库文件，免去手动绘制符号和封装
- **BOM 批量导库**：导入 BOM 表批量转换整板元件，适合生产前准备和供应链迁移
- **CI/CD 自动化集成**：使用 CLI 模式在脚本中自动拉取最新元件数据并更新 KiCad 库，确保设计库与供应链同步
- **教育与研究**：高校电子设计课程中，学生快速获取真实元件数据用于 KiCad 项目实践
