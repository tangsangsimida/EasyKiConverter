# EasyKiConverter 详细介绍

## 项目背景

中国电子工程师面临一个长期痛点：在嘉立创/LCSC 平台完成元器件选型后，需要将元件数据迁移到开源 EDA 工具 KiCad 中进行设计，但两个生态之间的数据格式完全不同。工程师不得不手动逐个绘制原理图符号、创建 PCB 封装、下载 3D 模型——一块 50 个元件的板子，仅建库就可能耗费一整天。

现有的 Python 脚本工具（如 easyeda2kicad.py）虽然提供了基础转换能力，但存在明显短板：无图形界面、无法批量处理、网络容错差、不支持分体式符号、缺少 BOM 导入能力。EasyKiConverter 正是为了解决这些实际问题而诞生——它以 C++17 重写整个转换链路，采用 MVVM 架构实现现代化桌面体验，覆盖从元件查找、数据获取、格式转换到 KiCad 库输出的完整工作流。

## 技术架构

### MVVM 四层架构

项目采用 Model-View-ViewModel 架构，职责清晰分离：

- **View 层**：Qt Quick (QML) 实现的现代化 UI，包含卡片式布局、响应式设计、深色/浅色主题、悬停预览、流畅动画
- **ViewModel 层**：管理 UI 状态与用户交互，包含元件列表、导出设置、进度跟踪、主题切换四个核心 ViewModel
- **Service 层**：业务逻辑核心，包含元件服务、并行导出服务、配置服务、缓存自愈管理、BOM 解析、CLI 参数处理、LCSC 图片服务、导出报告生成等 16 个顶层服务模块及导出子系统
- **Model 层**：数据模型定义，包含元件数据、符号数据、封装数据、3D 模型数据等

### 两阶段导出引擎

批量转换采用"预加载 → 并行导出"两阶段架构：

**预加载阶段**：并行从网络获取所有元件数据（最多同时处理 10 个元件，各 ResourceType 有独立并发上限），包括元件元数据、CAD 数据、3D 模型、预览图、数据手册，数据在验证阶段即缓存到内存。

**导出阶段**：按类型独立并行导出，每种类型有独立线程池配置：

| 导出类型 | 最大并发 | 说明 |
|----------|---------|------|
| 符号 (.kicad_sym) | 1 | 库级导出，单线程保证一致性 |
| 封装 (.kicad_mod) | 1 | 库级导出，单线程保证一致性 |
| 3D 模型 (WRL/STEP) | 2 | 弱网降为 1 |
| 预览图 | 4 | 弱网降为 2 |
| 数据手册 (PDF) | 2 | 弱网降为 1 |

### 统一网络架构

所有 HTTP 请求通过 `NetworkClient` 单例处理，采用"专用网络线程 + 按 ResourceType 并发控制"架构：

- 所有请求在独立网络线程中执行，不阻塞 UI
- 9 种 ResourceType 各有独立的并发上限（如组件元数据 10 并发、预览图 5 并发、3D 模型 3 并发）
- 自动重试 + 指数退避 + 随机抖动（缓解惊群效应）
- 弱网模式：超时翻倍、增加重试次数、降低并发数

### 缓存自愈体系

- LRU 缓存淘汰策略，支持自定义缓存目录和容量上限
- 缓存健康检查：损坏的缓存文件自动修复或清除
- 3D 模型缓存独立管理，默认不参与 LRU 淘汰，避免频繁重新下载大文件
- 异步 metadata 落盘，缓存命中路径与网络路径性能一致

## 核心功能详解

### 1. 全流程元件转换

从 EasyEDA/LCSC 获取元件数据，输出 KiCad 原生格式文件：

- **符号转换**：支持完整符号几何数据、引脚信息和属性转换，包括分体式符号（多单元符号）的正确处理
- **封装转换**：支持通孔和表面贴装封装、完整焊盘信息转换、多边形自定义焊盘、封装边界框自动生成
- **3D 模型**：自动下载并转换 3D 模型，支持 STEP 和 OBJ 格式下载，OBJ 可自动转换为 KiCad 所需的 WRL 格式，模型偏移参数自动计算，支持相对路径和绝对路径模式
- **数据手册**：可选导出元件 PDF 数据手册
- **预览图**：可选导出 LCSC 元件预览图

输出文件可直接在 KiCad 中使用：通过"管理符号库"和"管理封装库"导入即可。

### 2. 元件添加方式

三种方式灵活添加元件：

- **手动输入**：在输入框输入 LCSC 编号（如 C123456），回车添加
- **智能提取**：从剪贴板中自动识别和提取元件编号，支持从 BOM 表格、网页、文本中批量提取，自动过滤无效格式
- **BOM 文件导入**：支持 CSV 和 Excel 格式的 BOM 文件，自动解析并批量导入所有元件

### 3. 批量转换与并行处理

- 多元件同时转换，两阶段导出架构（预加载 → 按类型并行导出）
- 基于 QThreadPool 的线程池管理，每个元件作为独立任务
- 实时进度显示（进度条 + 状态文本 + 成功/失败计数）
- 错误隔离：单个元件转换失败不影响其他元件
- 导出报告：调试模式下生成详细的转换报告

### 4. CLI 命令行模式

支持纯命令行运行，无需 GUI，适用于自动化脚本和 CI/CD：

```bash
# BOM 批量转换
easykiconverter convert bom -i BOM.csv -o ./output --3d-model --datasheet

# 单个元件转换
easykiconverter convert component -c C12345 -o ./output

# 批量转换（从文件读取元件列表）
easykiconverter convert batch -i components.txt -o ./output

# 生成 Shell 自动补全脚本
easykiconverter --completion bash
easykiconverter --completion zsh
easykiconverter --completion fish
```

CLI 支持全部导出选项（符号/封装/3D模型格式/数据手册/预览图）、缓存配置（目录/容量）、弱网模式、更新模式（仅导出缺失或已变更文件）、调试模式、进度条显示等。

### 5. 图层映射系统

完整的嘉立创 EDA 到 KiCad 图层映射：

- 支持 50+ 图层类型（信号层、丝印层、阻焊层、助焊层、机械层、用户层、板边层、制造层）
- 自动单位转换（mil → mm）
- 内层映射支持（Inner1-32）
- 类型 "N" 文本自动转换到制造层
- 底层文本镜像处理

### 6. 几何转换引擎

- **椭圆弧计算**：完整移植 Python 版本算法，精确的 SVG 弧参数解析、圆心和角度计算、KiCad 格式输出
- **多边形焊盘**：自动生成 primitives 块、坐标转换、最小尺寸优化、KiCad 兼容性保证
- **SVG 路径解析**：完整解析 SVG path 数据，支持各种几何图元

### 7. 预览与可视化

- **符号/封装缩略图**：转换完成后自动生成缩略图预览，高速渲染
- **LCSC 预览图**：自动从 LCSC 下载元件实物图，支持列表缩略图和悬停放大预览
- **缓存机制**：已下载图片自动缓存，避免重复下载

### 8. 配置管理

- 所有设置修改即时自动保存，无需手动点击保存按钮
- 支持导出目录、导出类型、覆盖行为、3D 模型格式、3D 路径模式等完整配置
- 缓存目录可自定义，迁移时自动复用已有数据
- 磁盘缓存上限可配置（1MB - 1TB）
- CLI 参数可覆盖 GUI 配置，适合脚本场景

## 用户界面

### 现代化 GUI

- Material Design 风格卡片式布局
- Qt Quick 实现的流畅动画（按钮悬停、卡片进入、状态切换、加载动画）
- 无边框窗口设计，支持拖拽移动、边缘调整大小、全屏切换
- 退出确认对话框，防止意外关闭
- 键盘快捷键支持（Enter 添加、Ctrl+V 粘贴提取、Ctrl+C 开始转换等）

### 深色/浅色主题

- 全局样式系统（AppStyle），动态主题切换，平滑过渡动画
- 主题配置持久化，重启后保持上次选择

### 响应式布局

- 界面根据窗口大小自动调整组件布局
- 窗口缩放时过渡流畅
- 各尺寸窗口下均有最佳显示效果

## 性能指标

- **网络并发**：组件元数据 10 并发、CAD 数据 10 并发、预览图 5 并发、3D 模型 3 并发
- **导出并行**：5 种导出类型独立并行，互不阻塞
- **自动重试**：默认 3 次重试，指数退避（初始 1s，上限 8s），随机抖动 ±20%
- **超时控制**：默认 30 秒，弱网模式翻倍至 60 秒
- **弱网容错**：自动降级并发数，3D 模型失败不影响符号/封装导出
- **GZIP 压缩**：自动解压缩网络响应，减少传输量

## 跨平台支持

- **Windows** 10/11：exe 安装程序 + zip 便携版
- **Linux**：AppImage + tar.gz + Flathub + Arch Linux AUR（`yay -S easykiconverter`）
- **macOS**：dmg 镜像
- **构建系统**：CMake + vcpkg 依赖管理，全平台一键构建

## 测试与质量

- QtTest 框架：单元测试 + 集成测试 + 基准测试 + 手动测试场景
- Mock 支持：依赖注入模式，支持 Mock 网络请求
- 代码覆盖率：GCC/MinGW 支持，`cmake -DENABLE_COVERAGE=ON` 启用
- 代码规范：clang-format + qmlformat 自动格式化
- 版本管理：`manage_version.py` 统一同步 vcpkg.json / CMakeLists.txt / main.cpp 版本号
